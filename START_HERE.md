# OrionLead AI — Reviewer Package

What's in this folder:

- **`backend/`, `web/`, `mobile/`** — full project source code.
- **`mobile-app-apk/OrionLead-AI.apk`** — a ready-to-install Android app. Copy it to
  an Android phone and tap it to install (you may need to allow "install from unknown
  sources" once). It's pre-configured to reach the developer's backend over Wi-Fi, so
  a live demo requires being on the same network as the developer while their backend
  is running.
- **`RUN_BACKEND_STANDALONE.md`** — step-by-step instructions to run the backend and
  web app entirely on your own computer, independent of the developer's machine.
- **`OrionLead_AI_Graduation_Report.md`** / **`report/`** — the written report.

Recommended path to try the system on your own: open `RUN_BACKEND_STANDALONE.md` and
follow the web app steps — that's the fastest way to see it running without any
dependency on the developer being present.
